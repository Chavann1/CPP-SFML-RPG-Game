# C++ RPG Game Demo

A 2D RPG game demo written in C++ using SFML 3.0, showcasing real-time input handling, rendering, and basic gameplay systems.

---

## Features

* Player movement and interaction system
* Basic combat
* Pause system
* Asset/config-driven structure

---

## Technologies

* C++20
* SFML 3.0
* Visual Studio 2022

---

## Build & Run

### Requirements

* Visual Studio 2022 (v143 toolset)
* SFML 3.0 (64-bit, Visual C++ 17)

### Quick Setup

1. Download SFML 3.0 from the official website
2. Link SFML in your project (include + lib directories)
3. Copy SFML `.dll` files into the executable directory
4. Build and run the project

Detailed setup guide:
https://www.sfml-dev.org/tutorials/3.0/getting-started/visual-studio/

---

## Controls

* W / A / S / D — Movement
* Z — Attack
* X — Interact
* Esc — Pause

---

## Project Structure

* assets/ — game resources
* config/ — configuration files
* data/ — game data
* src/ — source code
